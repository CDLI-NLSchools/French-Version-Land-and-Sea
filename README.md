# Suivi de l'inertie thermique : terre vs océan

Cette activité interactive aide les élèves à comparer l'inertie thermique entre les régions continentales et maritimes à l'aide d'un tableau de températures et d'un graphique comparatif.

## Objectif

L'activité permet :
- d'attribuer automatiquement une date unique selon le prénom d'un élève ;
- d'ouvrir des cartes météorologiques pour deux régions : continentale et maritime ;
- d'observer les variations de température sur une journée ;
- de saisir les valeurs dans un tableau ;
- de générer un graphique comparatif pour interpréter les différences de température.

## Fonctionnalités

- Saisie du prénom de l'élève pour générer une date d'activité unique ;
- Choix du format horaire :
  - NL - Demi-heure (:30)
  - Labrador - Heure pile (:00)
- Ouverture de cartes météo interactives dans des fenêtres séparées ;
- Saisie des températures toutes les deux heures ;
- Génération automatique d'un graphique en ligne comparant les températures continentales et océaniques ;
- Interface entièrement en français.

## Fichiers du projet

- `index.html` : page principale de l'activité interactive ;
- `README.md` : documentation du projet.

## Utilisation

1. Ouvrir le fichier `index.html` dans un navigateur web.
2. Entrer le prénom de l'élève dans la zone prévue.
3. Vérifier le format d'heure sélectionné.
4. Cliquer sur les boutons pour ouvrir les cartes de la région continentale et de la région maritime.
5. Utiliser les commandes de navigation sur les cartes pour noter les températures toutes les deux heures.
6. Saisir les valeurs dans le tableau.
7. Cliquer sur le bouton "Générer le graphique comparatif" pour afficher les résultats.

## Technologies utilisées

- HTML
- CSS
- JavaScript
- Chart.js
- Nullschool Earth (cartes interactives)

## Remarque

Cette activité est conçue comme une ressource pédagogique interactive pour explorer le concept d'inertie thermique. Elle fonctionne comme une application web statique, sans installation ni dépendances supplémentaires.
